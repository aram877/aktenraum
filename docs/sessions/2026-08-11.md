## Bugs found and fixed

Both were found by verifying against the live stack rather than by tests.
**Committed under the user's explicit "commit all the changes" instruction** —
CLAUDE.md's rule 2 (no committing a bug fix without live confirmation) is
satisfied for #1, which was demonstrated live via an A/B against the running
stack, and waived by that instruction for #2.

1. **Stale tag cache hid freshly-propagated tags for up to 5 minutes.**
   `PaperlessGateway.listTags()` caches for 300s, but the propagator that
   *creates* tags runs in the auto-tagger — a different process — so the API's
   map predated them and every unresolvable tag id was silently dropped from
   library/inbox projections. Fixed in the **Node port only** (`listTagsCovering`,
   a one-shot invalidate-and-refetch); the Python API still has the bug and is
   slated for deletion at 4.15. Proven by an A/B on the live stack: a tag
   created out-of-band appeared immediately on Node and not on Python.
2. **transformers.js cached the reranker inside `node_modules`, not the mounted
   volume.** `env.cacheDir` is unset by default, so the ~545 MB ONNX model
   landed in an image layer — re-downloading on every rebuild and leaving a
   *truncated* file when a rebuild interrupted it, which surfaces as
   `Protobuf parsing failed` rather than a download error. Fixed in
   `core-ts/src/rag/reranker.ts`.
