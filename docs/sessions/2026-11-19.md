## Follow-up: tenancy decision (ADR-009) + Paperless permission spike

### Focus / scope

Before rebuilding auth (passkeys, sessions, scopes, per-service credentials), decide the tenancy model, because a new job puts the maintainer in charge of auth and client integration and aktenraum should get the same treatment.

### What shipped

- **[ADR-009](../adr/009-tenancy-households-spaces.md)** — Household → Members → Spaces, one home space per document, plus explicit per-document shares (viewer/editor, optional expiry, never rule-based). One `PolicyService` decides access. RAG payload gains `space_id` + `shared_with`; few-shot, history hint and dedup are scoped to the home space so private content can't leak through prompts. Encryption mapping for the later cloud feature (per-space keys, per-document keys for shares).
- **Paperless spike** (`scripts/spikes/paperless-perm-spike.mjs`, `paperless-perm-spike-2.mjs`, throwaway e2e stack only). Result: Paperless 2.20 enforces per-user/group document permissions correctly across every list/filter/search endpoint we use (36/36), revocation is immediate, only owners can delete/move/re-share. So Paperless enforces as well (option b).
- **Trap found**: tags/types/correspondents are owned by their creator and invisible to other users. Decision: shared household vocabulary with `owner = null` (names visible to all members, per-user `document_count` verified). Accepted privacy trade-off recorded in the ADR.

### Read-only audit of the current auth coupling (input for the auth ADR)

- User auth is contained: one `AuthGuard`, `@CurrentUser()` read in two places. `AuthUser` carries `passwordHash` and has no scopes/session/client id; it becomes the `Principal`.
- Coupling points: `type-fields.controller.ts` `requireUserOrSecret` bypasses the guard; the CSRF bypass is keyed on the internal secret; four copies of the secret comparison; one `WEBHOOK_SECRET` shared by five callers; the SSE live-counts stream never re-checks its session.
- Single-user assumptions: no owner columns, one admin Paperless token, no owner in the Qdrant payload, ingest source detection relies on "ownerless task", unscoped live counts.

### Live install state (read-only)

498 tags, 22 types, 85 correspondents all owned by the Paperless admin; 257 documents (195 admin-owned, 62 ownerless). The migration steps are in ADR-009.
