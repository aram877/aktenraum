### New package `apps/web-nuxt` (`@aktenraum/web-nuxt`)

- Nuxt 4, `ssr: false`, `nuxt generate` → static files for nginx. Tailwind v4 via `@tailwindcss/vite`.
- All Angular routes as file-based pages; `auth` / `guest` named route middleware; `default` (nav) and `bare` layouts.
- `@tanstack/vue-query` with the Angular query keys and staleTimes; composables per area (`useInbox`, `useLibrary`, `useDocuments`, `useTrash`, `useSettings`, `useUpload`, `useAuth`).
- Live counts: `createLiveCountsStream` + `plugins/live-counts.client.ts`, which opens/closes the EventSource by observing the `me` query. Ask: `useAnswerStream` over the ported SSE parser.
- Shared `useHydratedForm` + `DocumentFieldsForm` (v-model) for both detail pages; `useShortcuts` for inbox keyboard shortcuts.
- `/health` uses Nuxt's `useFetch` on purpose, as the one contrast to Vue Query.

### Behaviour differences vs Angular (deliberate)

- Approve/reject/bulk-approve invalidate `["library"]` as well as `["inbox"]` (spec requirement; Angular only invalidated the inbox).
- Signed-out state is `null` in the `me` cache. Angular's `setQueryData(ME_KEY, undefined)` is a no-op in TanStack v5.
- Keyboard approve/reject is ignored while a mutation is pending (no double approve).
- Not-found page says "Seite nicht gefunden" instead of the stale "Noch nicht portiert" copy.
