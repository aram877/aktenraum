## Decisions and divergences recorded

- **`asyncio.shield()` has no Node equivalent, and needs none.** The Python
  shields the lifecycle-flipping PATCH against cancellation on SIGTERM. In
  Node an in-flight `await` is not cancelled by a signal — shutdown sets an
  abort flag and closes queues, and anything already in flight completes. The
  guarantee comes for free; do not add cancellation support later without
  restoring an equivalent guard.
- **`PaperlessClient.getTagId` is now public** in `core-ts`. The Python reaches
  into `_get_tag_id` with a `noqa` for exactly this read-only lookup.
- **One accepted cosmetic divergence** in the few-shot block: Python's
  `json.dumps` renders the float default `1.0`, `JSON.stringify` renders `1`.
  Only reachable when an exemplar has no `ai_confidence` field at all. Forcing
  it would need a sentinel-token string replace that risks emitting malformed
  JSON into the prompt.
