## Follow-up: full-app review + worker pipeline hardening

### Focus

Review the whole app (four parallel read-only reviews: api, worker + core, SPA, infra/docs), then fix the worker pipeline findings first. OpenSpec change: `openspec/changes/harden-worker-pipeline/`.

Commit: fix(tagger): harden the worker pipeline against data loss and stalls.

### Repo state

Tests 594 → 615 (core 170 → 175, worker 105 → 121). `pnpm --filter @aktenraum/api typecheck` was red on `main` (3 errors in `apply-schema.test.ts`); now green. `scripts/e2e-worker.sh` 20/20. Reprocess verified live by the maintainer before commit.

### What shipped

- **Data loss:** `PaperlessClient.patchDocumentAiFields` merges into the existing `custom_fields` array instead of replacing it, so non-AI custom fields survive extraction/reprocess.
- **State guard:** `processApprovedDocument` skips documents that no longer carry `ai-approved` (`skip_not_approved`) — duplicate poller/webhook enqueues and triggers for pending docs no longer propagate.
- **RAG safety:** indexer embeds before deleting old chunks; `reindex-metadata` now uses `updateMetadataByDocId` (payload only) when chunks exist; startup reconcile enqueues every `ai-propagated` doc with zero chunks; nothing is queued when `QDRANT_URL` is unset.
- **LLM bounds:** Ollama structured calls time out (`LLM_TIMEOUT_SECONDS`, 300) and request `num_ctx` (`OLLAMA_NUM_CTX`, 24576). Transient failures defer to the next poll, third strike tags `ai-error` (`transient.ts`).
- **Model setting:** the worker resolves the extraction model from `/api/settings/active-llm-model` (`active-model.ts`, 60 s cache, env fallback) — the Node port had dropped this.
- **Smaller:** Anthropic `complete` sends `system` as a top-level param (was rejected by the API); `applyTags` merges onto a fresh tag read; non-finite `min_confidence` disables a rule; `getEntityNameMap` paginates; webhook body capped at 64 KiB.
- **Tests:** `services/auto-tagger/src/pipeline.test.ts` — first flow-level tests for extraction, propagation, indexing, metadata reindex, reconcile, active model.

### Diagnosed but not fixed

- Dedup still compares the retired `ai_monetary_amount`, so only reference-number overlap matches.
- Ask/RAG: retrieval skipped when the structured filter returns 0 docs; RAG docs crowded out of the 15 prompt slots; prompt injection via email ingestion.
- SPA: delete / star / duplicate UI / type-specific fields missing; Ask stream can hang without a `final` event; no global 401 handling; upload tracker keyed by filename.
- API: `listNamed` 200-entry cap; uploads buffered without multer limits; `PaperlessRequestError` → 500.
- Ops: nginx headers missing on every SPA route; restore runbook references deleted env files; CI has no image build / e2e; widespread Python-era doc drift.

## Follow-up: Ask retrieval fixes (step 2)

Commit: fix(api): let RAG reach the Ask prompt and stop the reranker OOM. OpenSpec: `openspec/changes/fix-ask-retrieval/`.

### What shipped

- **RAG before "nicht gefunden"**: `/api/ai/answer/stream` runs RAG before the empty-result check; no-match only when structured search and RAG are both empty.
- **Slot order**: RAG-ranked docs first (≤5), then structured results, capped at 15 (`promotePromptResults`). RAG-only docs now carry correspondent + document type names.
- **Filter parity**: `vectorFilterFor` — tags dropped, correspondent mapped case-insensitively onto known names, one unfiltered retry when the filtered search is empty.
- **Citations**: resolved only against prompt docs.
- **Partial totals**: per-type sums labelled UNVOLLSTÄNDIG when the structured total exceeds the prompt.
